# 📖 よみあげカメラ

スマホのカメラに映った文章を、**操作なしで自動的に**音声で読み上げてくれるWebアプリです。

長い本を読むときのために作られています。スタンドなどでスマホを固定して本にカメラを向け、
一度「読書をはじめる」を押したら、**あとはページをめくるだけ**。
新しいページが映るたびに自動で文字を読み取り、読み上げが続きます。

## 使い方

1. アプリを開く(カメラの使用を許可してください)
2. スマホを固定し、本のページ全体がカメラに映るようにする
3. 「▶ 読書をはじめる」をタップ(初回は文字認識エンジンの準備に少し時間がかかります)
4. 読み上げが終わったらページをめくる — 新しいページを自動で認識して読み上げます
5. やめるときは「⏹ 読書をおわる」

補助機能:

- **⏭ このページを飛ばす** — いま読んでいるページの読み上げを中断
- **速さスライダー** — 読み上げ速度を 0.5〜2.0 倍で調整
- **縦書きの本を読む** — 小説など縦書きのページ向けの認識モードに切り替え
- 読書中は画面が自動で暗くならないようにします(Wake Lock)

## 自動読み上げの仕組み

| 段階 | 内容 |
|------|------|
| 1. 監視 | カメラ映像を約0.4秒ごとに縮小画像で比較し、「ページめくり中(動きあり)」か「静止した」かを判定 |
| 2. 新ページ判定 | 静止した画面が前回読み取った画面と大きく違うときだけ、新しいページとして処理 |
| 3. 文字認識 | [Tesseract.js](https://tesseract.projectnaptha.com/)(日本語横書き・縦書き+英語)で端末内OCR |
| 4. 重複防止 | 認識した文章が直前に読んだ文章とほぼ同じなら読み上げない(同じページの誤再読を防ぐ) |
| 5. 読み上げ | Web Speech API で文単位に読み上げ。読み上げ中に次のページをめくれば順番に続けて読む |

画像の処理はすべて端末内(ブラウザ内)で行われ、撮影内容が外部サーバーに送信されることはありません。
OCRエンジン(Tesseract.js, Apache-2.0)と認識データは `vendor/` に同梱しているため、外部CDNにも依存しません。

## 動かし方

カメラAPIの制約により **HTTPS(または localhost)での配信が必須** です。ビルドは不要です。

### GitHub Pages で公開する(スマホで使うにはこれが簡単)

1. GitHubリポジトリの Settings → Pages を開く
2. Source を「Deploy from a branch」にし、公開したいブランチと `/ (root)` を選択
3. 表示されたURL(`https://<ユーザー名>.github.io/yomiage/`)をスマホで開く
4. ホーム画面に追加すると、アプリのように全画面で使えます(PWA対応)

### ローカルで試す

```bash
python3 -m http.server 8000
# → http://localhost:8000 をブラウザで開く
```

## うまく読み上げてもらうコツ

- スマホはスタンド等で固定する(手持ちだと「静止」を検出しにくくなります)
- ページ全体に明るい光が当たるようにする
- 印刷された横書き・縦書きの活字が対象です(手書き文字は苦手です)

## 対応ブラウザ

- iOS: Safari(iOS 16.4以降推奨)
- Android: Chrome

※読み上げの声質は端末・OSに搭載されている音声エンジンに依存します。
