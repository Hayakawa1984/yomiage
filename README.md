# 📖 よみあげカメラ

スマホのカメラに映った文章を音声で読み上げるWebアプリです。

長い本を読むときのために、**スマホを操作しなくても、本のページをめくるだけで自動的に読み上げが続く**のが特徴です。

## 使い方

1. アプリを開き、本のページにカメラを向ける(スタンド等でスマホを固定すると快適です)
2. 「▶ 読書をはじめる」をタップ(初回は文字認識エンジンのダウンロードで少し待ちます)
3. いま映っているページが自動で読み上げられます
4. **次のページをめくるだけ**で、新しいページを検出して続きを読み上げます
5. 終わるときは「⏹ 読書をおわる」をタップ

その他の操作:
- ⏭ このページを飛ばす — いま読んでいるページの残りをスキップ
- 速さスライダー — 読み上げ速度の調整(0.5〜2.0倍)
- 縦書きの本を読む — 縦書きの小説などを読むときにオンにする(縦書き専用の認識モデルに切り替わります)

## 自動読み上げの仕組み

| ステップ | 処理 |
|---|---|
| 1. 動き検出 | カメラ映像を縮小グレースケールで常時比較し、ページめくり中(動きあり)か静止したかを判定 |
| 2. 新ページ判定 | 静止した映像が前回読み取ったページと十分違うときだけ文字認識を実行 |
| 3. 文字認識 | Tesseract.js で日本語+英語をOCR(すべて端末内で処理) |
| 4. 重複防止 | 認識テキストを直前に読んだ内容と類似度比較し、同じページの再読を防止 |
| 5. 読み上げ | Web Speech API で文単位に読み上げ。読み上げ中にページをめくれば次ページが順番待ちに入る |

さらに、読書中は画面スリープを防止(Wake Lock)するので、長時間のハンズフリー読書ができます。

文字認識エンジンと言語データはすべてこのリポジトリに同梱(`vendor/`)しており、画像の処理も含めて端末内(ブラウザ内)で完結します。撮影内容が外部サーバーに送信されることはありません。

## 動かし方

ビルド不要の静的Webアプリです。カメラAPIの制約により **HTTPS(または localhost)での配信が必須** です。

### ローカルで試す(PC)

```bash
python3 -m http.server 8000
# → http://localhost:8000 をブラウザで開く
```

### スマホで使う(GitHub Pages で公開)

1. GitHubリポジトリの Settings → Pages を開く
2. Source を「Deploy from a branch」にし、公開したいブランチと `/ (root)` を選択
3. 表示されたURL(`https://<ユーザー名>.github.io/yomiage/`)をスマホで開く
4. ホーム画面に追加すると、アプリのように全画面で使えます(PWA対応)

## 対応環境

- iOS: Safari(iOS 16.4以降推奨。それ未満は画面スリープ防止が効きません)
- Android: Chrome

※読み上げの声質は端末・OSに搭載されている音声エンジンに依存します。
※文字認識の精度について: 印刷された横書きの本ははっきり写せばおおむね読み取れますが、手書き文字・装飾フォント・暗い場所は苦手です。ページ全体が画面に入り、ピントが合った状態で静止させるのがコツです。

## 技術構成

| 機能 | 使用技術 |
|---|---|
| カメラ | `getUserMedia` API(背面カメラ優先) |
| 動き・新ページ検出 | Canvasによるフレーム差分(縮小グレースケール比較) |
| 文字認識(OCR) | [Tesseract.js](https://tesseract.projectnaptha.com/) v7(横書き: `jpn+eng` / 縦書き: `jpn_vert`、`vendor/`に同梱) |
| 読み上げ | Web Speech API(`speechSynthesis`) |
| スリープ防止 | Screen Wake Lock API |
| 重複読み防止 | 文字bigramのDice係数による類似度判定 |
